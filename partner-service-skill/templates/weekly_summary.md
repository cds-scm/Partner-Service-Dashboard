# Template: Weekly Summary

สรุปรายสัปดาห์สำหรับทีมงาน เน้นกระชับ ดู trend และ action ที่ต้องทำสัปดาห์หน้า

## จำนวน Slides: 4-5 slides

### Slides ที่ต้องมี

1. **cover** — "Weekly Update" + ช่วงวันที่ + สัปดาห์ที่เท่าไหร่
2. **week_kpi** — KPI หลัก 4 ตัว (FCR, Abandon, Reach Rate, Pending)
3. **daily_trend** — กราฟ call volume รายวัน (จ-ศ)
4. **highlight** — 3 ประเด็นเด่นสัปดาห์นี้ (ดี/ไม่ดี/ต้องติดตาม)
5. **next_week** — สิ่งที่ต้องทำหรือติดตามสัปดาห์หน้า

### Design Style

```
สี header bar   : #6C5CE7 (ม่วง — ต่างจาก monthly ที่ใช้ดำ)
สี accent       : #29C6C0 (เขียวอมฟ้า)
สี background   : #FFFFFF
สไตล์           : เรียบง่าย ข้อมูลชัดเจน
```

### Narrative Tone

- ภาษาพูดปานกลาง ไม่เป็นทางการมาก
- เน้น "สัปดาห์นี้เกิดอะไรขึ้น" และ "ต้องทำอะไรต่อ"
- bullet points สั้นๆ แต่ละข้อไม่เกิน 1 บรรทัด

### Week KPI Layout

แสดง 4 การ์ดใหญ่ เรียงแถวเดียว:
- ค่า KPI + เปรียบเทียบกับสัปดาห์ก่อน
- icon แทน label (📞 Call, 📧 Mail, 🚫 Abandon, ⏳ Pending)

### Highlight Slide

3 section แนวนอน:
- 🟢 ไฮไลต์ดี: สิ่งที่ทำได้ดีสัปดาห์นี้
- 🔴 ประเด็นที่ต้องแก้: ปัญหาเร่งด่วน
- 🟡 ติดตาม: สิ่งที่ต้องดูต่อเนื่อง

### Next Week Slide

Checklist style — แต่ละ item มี:
- checkbox (ยังไม่ทำ)
- รายการที่ต้องทำ
- ผู้รับผิดชอบ
